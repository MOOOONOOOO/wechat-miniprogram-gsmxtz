# 雨水一盒 · 接收动画 Demo

这是“雨水一盒”模式的接收侧交互原型，使用三段同规格 MP4 组成一个明确的状态机：

1. 首帧待机：时间线 1 停在首帧。
2. 第一次点击“开启”：完整播放时间线 1。
3. 等待：自动切换并循环播放时间线 2。
4. 第二次点击“再次开启”：播放时间线 3。
5. 时间线 3 播放完毕：停在终帧，并展开代码绘制的信纸和歌曲卡片。

## 本地运行

```powershell
node server.js
```

然后打开 <http://127.0.0.1:4173>。

Demo 里的“直接查看信件”只用于评审时快速跳过视频，正式小程序版本可以去掉。

## 小程序迁移映射

- HTML `video` → 小程序 `<video>`，三个视频绝对定位在同一容器中。
- `ended` 事件 → `bindended`。
- `play()` / `pause()` / `seek()` → `wx.createVideoContext()`。
- `data-state` → 页面 `data` 中的 `animationState`。
- 信纸 DOM → WXML + WXSS；出现动画用 CSS transition/animation。

为了减少切换黑帧，小程序侧也建议保留三个叠放的视频实例并预加载，状态切换时只改变透明度和层级。
